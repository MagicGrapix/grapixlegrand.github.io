# Image super-resolution article sources

Based on Quentin Guignard’s May 29, 2023 report and code for ETH Zurich MFCGV23 exercise 6. The GitHub repository is private; the article deliberately has no inaccessible public source link. No training was rerun and no numerical benchmark improvement is claimed.

The ten WebP images are lossless panel extractions from the original report figures, not new predictions. The added `parrot-low-resolution.webp` is the original low-resolution panel exactly extracted from the report, enlarged there as shown; it is not a newly downsampled image. Each image has a provenance sidecar (`*.webp.json`). Exact source names, crop boxes and output dimensions are recorded in pages/image-super-resolution/images/sources.json. The Matplotlib exports have a one-pixel difference between some panel widths; both comparator panels display the complete same scene framing. No generative retouching, sharpening or color adjustment was performed. The two training plots retain their original plotted data and axes; HTML captions supply readable legends.

Code review found that evaluation accumulates batch metrics rather than averaging them and labels 1-SSIM as SSIM. The archived table is omitted, and the article discloses this. Learning-rate runs have unequal budgets (1000 epochs versus approximately 2000 for baseline), explicitly stated in the text and captions. The residual model follows the assigned architecture. The independent shuffled train/validation splits and shallow state_dict copy should also be corrected before any fresh benchmark; historical curves are presented as observations, not independently verified benchmark scores.

Add future supplementary articles to cards/more-projects.json (root-relative links and images). This leaves the six selected homepage cards unchanged. Articles remain pages/<slug>/article.md plus template.html; npm run build generates /projects/, article HTML and sitemap entries. The shared comparison component is optional and progressively enhances two visible images with horizontal pointer dragging. The divider itself is a keyboard-accessible `role="slider"` with a 48px full-height handle; there is no separate lower range control. Pointer capture starts on pointerdown, the handle uses `touch-action: none`, and the image body retains vertical scrolling. The first comparison offers Bicubic / Low resolution buttons with `aria-pressed`; they replace only the left panel, preserving the CNN result on the right.
